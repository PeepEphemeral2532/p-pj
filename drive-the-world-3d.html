      About this app / data sources

      Map style & 3D buildings: OpenFreeMap "Liberty" (built from OpenStreetMap data). Terrain elevation: public Terrarium DEM tiles. Sky/lighting is fixed (no time-of-day or seasonal simulation). Aerial imagery: Esri World Imagery, toggleable with an optional 25% map-opacity blend, available on the main view, minimap, and big map. Note: this is styled map/terrain data, not a custom 3D game engine — individually textured/lit building windows and modeled vehicles (like fully custom driving games) aren't something achievable from open map data alone. Search & reverse geocoding: Nominatim. Routing: GraphHopper Directions API (a shared default key is pre-filled; you can swap in your own free key). Autodrive follows a calculated route exactly when one exists, or otherwise wanders the real OSM road network (mostly going straight through intersections, occasionally taking a random turn) using live Overpass road data. Turn-by-turn narration uses your browser's built-in text-to-speech. Hobby project, not affiliated with OpenStreetMap, OpenFreeMap, GraphHopper, or Esri.
